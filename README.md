# 🎲 Megapoly 

¡Bienvenido! Este es el **primer proyecto integral** que 
desarrollé como programador. Fue el proyecto final de mi formación inicial y 
representa el momento en el puse en práctica los conocimientos que apredí.

Desarrollar una versión de un juego de tablero tan complejo como el Monopoly fue un reto técnico que me 
obligó a entender a fondo la lógica de la programación orientada a objetos y sus principales fundamentos como la herencia, poliformismo, abstración y poliformismo.

### Detalles Técnicos
* **Lenguaje:** 100% Java.
* **Interfaz Gráfica:** Desarrollada íntegramente con la librería **Swing** (JFrame, JPanel, Graphics).
* **Paradigma:** Programación Orientada a Objetos (POO).

###  Ejecución desde consola
Si prefieres no usar un IDE, puedes copilar y ejecutar el juego directamente desde la
terminal.

**Requisitos de Sofware**
Para este proyecto necesitas el kit de desarrollo de Java (JDK), que incluye el compilador (`javac`) y el entorno de 
ejecución (Runtime/`java`). Puedes descargarlo directamente [Java SE Downloads](https://www.oracle.com/java/technologies/downloads/)

### Instalación en Linux

Para instalar el JDK en sistemas basados en Linux, ejecuta el comando correspondiente a tu distribución:

**Debian / Ubuntu**
```bash
Debian/Ubuntu: sudo apt install default-jdk
```
```bash
Arch / Manjaro: sudo pacman -S jdk-openjdk
```
